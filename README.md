# Testing Inteligente · Material de repaso

Páginas visuales para repasar el curso [Testing Inteligente](https://www.trainingit.es/producto/testing-ia/) en cuatro ejes: fundamentos (glosario), herramienta (playwright), proceso (skills) y artefactos (specs).

Web publicada: <https://testing-ia-trit.github.io/testing-ia-repaso/>

Organización GitHub de Training IT para este curso: https://github.com/Testing-IA-TrIT

Repositorio de este sitio: https://github.com/Testing-IA-TrIT/testing-ia-repaso

## Contenido

La portada (`index.html`) presenta cuatro ejes. Cada eje es una página:

| Eje | Página | Qué responde |
| --- | --- | --- |
| Fundamentos | `glosario.html` | Qué significa cada término del curso |
| Herramienta | `playwright.html` | Cómo escribir una buena prueba con Playwright |
| Proceso | `skills.html` | Qué hace cada pipeline y cada skill, y qué archivos se pasan |
| Artefactos | `specs.html` | Cómo llega un requisito a su prueba. Al final, los journeys (`#journeys`) |

Los estilos y los scripts están en `assets/`. Las decisiones sobre el sitio, con su motivo, están en `docs/decisions/`. Las instrucciones para agentes de IA están en `AGENTS.md`.

## Ver en local

Es HTML, CSS y JavaScript sin build ni dependencias. Abre `index.html` en el navegador.

## Publicar

GitHub Pages publica la rama `main` desde la raíz. Cada push a `main` actualiza la web.
