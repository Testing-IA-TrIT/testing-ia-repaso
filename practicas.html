Buenas prácticas

Una prueba que puedes creer

Una prueba en verde no basta. Debe comprobar el requisito, encontrar los elementos como el usuario y no depender de otras pruebas. Estas prácticas te sirven para escribir pruebas y para revisar las que genera un agente.

    Una prueba que pasa no cumple necesariamente las prácticas. Una prueba que cumple las prácticas puede comprobar el resultado incorrecto. Revisa también el requisito.
